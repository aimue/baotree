# 报数：原生微信标题预览

首个本地切片仅提供活动标题输入和同页原文预览。没有活动创建、持久化、分享、登录、头像、统计、CloudBase、Three.js 或埋点。

## 本地检查

需要 Node.js 22 或以上及 npm。没有第三方依赖，无须执行 `npm install`。

```sh
npm test
npm run check
```

测试直接执行实际页面脚本，以隔离的 `Page` 和 `setData` 模拟页面状态。
静态检查覆盖 JavaScript 语法、JSON、页面文件和本切片的模板约定。
它们不编译 WXML/WXSS，不验证微信渲染、键盘、输入法或真机性能。
静态约定检查不是完整解析器，也不是安全审计工具。

## 在微信开发者工具中导入

1. 打开微信开发者工具，导入本项目根目录。
2. 在工具中绑定你有权使用的项目身份。仓库未提供 AppID。
3. 使用本机配置保存 AppID，避免提交账号配置或 `project.private.config.json`。
4. 确认工具识别 `miniprogram/` 为小程序目录。
5. 编译并进入「报数」页面。

本机身份配置不得加入共享源码。导入或编译所需身份不可用时，保留「微信编译未验证」，不要填入虚构 AppID。
仓库没有额外构建命令。微信编译由开发者工具执行，Node 检查不能替代编译。

## 行为

- 页面初始输入为空；预览显示独立说明「尚未输入活动标题。」。
- 输入后直接预览原文，不修剪空格、不替换字符、不设置业务长度上限。
- 纯空格不是空字符串；页面仍保留原值。长标题应换行。
- 清空后回到独立空态。退出或重新创建页面后不保留标题。
- 页面明确提示「仅当前页面预览，不会保存。」，不创建任何活动。
- 点击可见标签会请求聚焦输入框。焦点边界由页面界面状态控制。
